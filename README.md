# Hebrew-Small-Models-Planning

Planning repository for work on small language models for Hebrew.

Status as of 2026-09-22: repository created; scope is being captured from a voice
note. `plan.md` will hold the transcribed brief and the plan derived from it.

## Layout

| Path | Contents |
| --- | --- |
| `plan.md` | The plan — goals, constraints, open questions |
| `audio/` | Source voice notes (the raw dictation the plan was derived from) |
| `transcripts/` | Verbatim transcripts of the files in `audio/` |
